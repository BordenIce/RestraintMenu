# 🥐 Restaurant Menu — Delicious Cafe

A stylish, mobile-friendly landing page and menu for a bakery cafe. Browse top products, explore categories, check featured treats and find contact info — all in a clean, warm design.

Built with **pure HTML, CSS and vanilla JavaScript** — no frameworks, no build step.

🔗 **Live demo:** https://bordenice.github.io/Restraint-Menu/

---

## ✨ Features

- **Hero section** with navigation, headline and call-to-action buttons
- **Top Products** — grid of product cards with price and an *Add* button
- **Promo banner** — "20% Off Your First Order"
- **Explore More** — category tabs (Cake, Muffins, Croissant, Bread, Tart, Favorite) with an animated underline and a photo gallery
- **About us** block
- **Featured Treats** — highlighted pastries with prices
- **Footer** with contact details, social links and recent news
- **Responsive design** — adapts to mobile screens
- Google Fonts (Playfair Display, Poppins) and Font Awesome icons

## 🛠 Tech Stack

| Technology | Usage |
|------------|-------|
| HTML5 | Page structure and semantic markup |
| CSS3 | Grid, Flexbox, custom styling, media queries |
| JavaScript (vanilla) | Category tabs and gallery rendering |
| Google Fonts | Playfair Display, Poppins |
| Font Awesome 5 | Social media icons |

## 📁 Project Structure

```
Restraint-Menu/
├── Index.html     # page markup
├── Style.css      # styles
├── Scrypt.js      # category tabs / gallery logic
└── images/        # product, gallery and footer images
```

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/BordenIce/Restraint-Menu.git

# Go to the project folder
cd Restraint-Menu

# Open Index.html in your browser
```

Or run a local server:

```bash
python -m http.server 8000
# open http://localhost:8000
```

## 🌐 Deployment

Hosted on **GitHub Pages**: *Settings → Pages → Deploy from branch → `main` / root*.
